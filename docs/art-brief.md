# Art Brief — Hit Lab

## Specs

- Base resolution: 480×270
- Tile size: 16×16
- Player: 16×24 or 24×32
- Dummy: 24×24
- Palette: limited, shared across player / dummy / stage

## Assets needed

**Player (24×32 max)**
- Idle
- Run
- Jump
- One attack

**Dummy (24×24)**
- Idle
- Hurt

**Stage (16×16 tiles)**
- Floor
- Wall
- Corner
- 1–2 props optional
